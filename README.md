# Pixel Flow — клон + генератор рівнів із фото

Гра в браузері: конвеєр із поросятами-турелями, 3–5 вертикальних черг, 5 лотків, бустери.

## Як грати

1. Відкрий сторінку.
2. Тап по **передньому** поросяті в будь-якій черзі — воно виходить на конвеєр.
3. Порося стріляє **перпендикулярно** до стрічки, лише по свій колір; чужий колір блокує постріл.
4. Порося з залишком заряду після кола сідає в лоток. Якщо всі 5 лотків зайняті — програш.
5. Місткість конвеєра обмежена (5–8 залежно від рівня) — запускати все одразу не вийде.

## Фото → рівень

Кнопка **📷 фото** у правому верхньому куті: вибери будь-яке зображення — воно стиснеться до 44 пікселів завширшки, квантується у 6 кольорів і стає рівнем.
